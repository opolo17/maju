# 새 면접 설정 — 예시 더미 데이터

`/interview/new` 폼 테스트용. **채용 공고** / **면접 족보** 영역에 그대로 복사해 붙여넣으면 됩니다.  
페르소나·피어 강도·시간은 각 예시 아래 추천값을 참고하세요.

## 예시 1. IT 신입 백엔드 개발자

**추천 설정:** 페르소나 `압박 면접관` · 피어 `보통` · `15분`

### 채용 공고

```
[회사] 그로스랩 (GrowthLab) — B2B SaaS 스타트업, Series A

[직무] 백엔드 개발자 (Junior)

[주요 업무]
- Node.js / TypeScript 기반 REST API 설계 및 구현
- PostgreSQL 스키마 설계, 쿼리 최적화
- AWS (ECS, RDS) 운영 및 모니터링
- 프론트엔드·PM과 협업하여 제품 기능 출시

[자격 요건]
- 컴퓨터공학 또는 관련 전공 (4년제 졸업 또는 졸업 예정)
- JavaScript/TypeScript 실무 또는 프로젝트 경험 1년 이상
- RDBMS 사용 경험 (PostgreSQL 우대)
- Git 기본 워크플로우 이해

[우대 사항]
- 스타트업 또는 애자일 환경 경험
- Docker, CI/CD 파이프라인 경험
- 오픈소스 기여 또는 사이드 프로젝트

[근무 조건]
- 정규직, 수습 3개월
- 서울 강남 · 주 2일 재택
- 연봉: 면접 후 협의 (3,500만~4,500만)
```

### 면접 족보 (선택)

```
예상 질문
- 자기소개 (1분)
- 지원 동기: 왜 백엔드? 왜 스타트업?
- 최근 프로젝트에서 가장 어려웠던 기술적 문제와 해결 과정
- API 설계 시 RESTful 원칙을 어떻게 적용했는지
- 트랜잭션 / 동시성 이슈 경험
- 3년 후 커리어 목표

STAR 메모 (프로젝트)
S: 팀 프로젝트에서 동시 주문 시 재고 이중 차감 버그 발생
T: 재고 정합성 보장 API 수정 담당
A: PostgreSQL SELECT FOR UPDATE + 트랜잭션 적용, 통합 테스트 추가
R: 부하 테스트에서 race condition 0건, 배포 후 CS 문의 감소

약점 대비
- "경력이 짧다" → 사이드 프로젝트·오픈소스로 보완, 학습 속도 강조
```

## 예시 2. 마케팅 인턴

**추천 설정:** 페르소나 `온화한 경청형` · 피어 `낮음` · `15분`

### 채용 공고

```
[회사] 뷰티브랜드 '루미에르' — D2C 화장품

[직무] 마케팅 인턴 (6개월, 정규직 전환 검토)

[주요 업무]
- Instagram / TikTok 콘텐츠 기획 및 업로드 지원
- 인플루언서 캠페인 운영 (섭외, 일정, 성과 리포트)
- GA4·Meta 광고 대시보드 모니터링
- 프로모션 페이지 카피 검수

[지원 자격]
- 대학 재학생 또는 졸업 1년 이내
- SNS 콘텐츠 제작·운영 경험
- Excel / Google Sheets 능숙
- 뷰티·라ifestyle 카테고리 관심

[우대]
- Canva, CapCut 등 영상·이미지 툴 사용
- 퍼포먼스 마케팅 용어 이해 (CTR, ROAS, CPA)
- 영어 의사소통 가능
```

### 면접 족보 (선택)

```
- 인스타그램 릴스 1개 기획안 간단히 설명할 준비
- "실패한 캠페인"보다 "개선한 캠페인" 스토리 준비
- 브랜드 톤: 밝고, 신뢰감, 20~30대 여성 타깃
```

## 예시 3. 금융권 대졸 공채 (일반 직무)

**추천 설정:** 페르소나 `꼬리 질문형` · 피어 `높음` · `30분`

### 채용 공고

```
[회사] ○○은행 — 2026년 하반기 대졸 신입 공채

[직무] Digital Banking Unit (디지털금융)

[업무 내용]
- 모바일 뱅킹 앱 UX·기능 기획 지원
- 데이터 기반 고객 세그먼트 분석
- 핀테크 협업 프로젝트 PMO
- 내·외부 이해관계자 커뮤니케이션

[응시 자격]
- 4년제 대학 졸업(예정)자
- 금융·경영·IT·통계 등 관련 전공 무관
- 병역 필 또는 면제
- 해외여행 결격 사유 없음

[전형]
- 서류 → AI 역량검사 → 1차 면접(그룹) → 2차 면접(임원)
- 우리는 1차 그룹 면접 대비용 시뮬레이션

[핵심 역량]
- 고객 중심 사고, 윤리 의식, 협업, 디지털 리터러시
```

### 면접 족보 (선택)

```
그룹 면접 대비
- "디지털 전환에서 은행이 가져야 할 강점/약점" 1분 의견
- 팀 토론 시: 듣기 → 요약 → 보완 발언 패턴
- 윤리: 고객 정보 보호, 이해충돌 회피 사례

인성 예상
- 본인의 강점·약점 (약점은 극복 노력과 함께)
- 스트레스 상황 대처
- 10년 후 은행원으로서의 모습
```

## 예시 4. 대학원 석사 면접 (연구실)

**추천 설정:** 페르소나 `꼬리 질문형` · 피어 `보통` · `30분`

### 채용 공고

```
[학과] ○○대학교 컴퓨터공학과
[지도교수] 김○○ 교수 (Human-Computer Interaction Lab)

[모집] 석사과정 2026학년도 후기

[연구 분야]
- 대화형 AI·챗봇 UX
- 음성·멀티모달 인터페이스
- 사용자 연구 (User Study, A/B Test)

[지원 자격]
- 학사 학위 취득(예정)자
- 프로그래밍 (Python) 및 통계 기초
- 영어 논문 읽기 가능

[제출 서류]
- SOP, CV, 성적증명, 추천서 2부

[면접]
- 10분 발표 (학부 연구/프로젝트) + 20분 Q&A
- 연구 fit, 학업·연구 열의, 영어 질의응답
```

### 면접 족보 (선택)

```
발표 요약 (3분 버전)
- 학부 졸업작업: 챗봇 프로토타입 + 20명 사용자 테스트
- 한계: LLM 미연동, 정량 지표 부족 → 석사에서 보완하고 싶음

교수님 논문 1편 읽고 질문 준비
- "Why this lab?" → HCI + AI 교차, 사용자 중심 설계 관심

예상 꼬리질문
- 연구에서 통제 변수는?
- p-value 해석, 표본 크기 20명의 한계
- 5년 후 PhD vs industry
```
